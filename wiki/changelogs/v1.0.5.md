# v1.0.5

## 新增
- 新增登录页面与认证流程，支持登录状态处理、请求鉴权与设置持久化。
- 新增 vConsole 调试工具，并支持按条件展示。
- 新增 shared 共享模块，统一 Electron、uTools、Web 端的文件、服务、设置等工具代码。
- 新增构建与自动发布脚本，完善 GitHub Actions 发布流程。
- 更新应用图标，覆盖 Windows、macOS、Web 与 uTools 平台。

## 修复
- 修复文件链接下载失败、复制链接失效的问题。
- 修复 Windows 下打开文件所在位置失败的问题。
- 修复 Windows 文件夹名称包含特殊字符时解析异常的问题。
- 修复持久层相关 bug。
- 修复 macOS 打包报错。
- 修复认证处理、部分页面路径/地址显示异常及文案错误。

## 优化
- 优化按钮显影逻辑与页面滚动条白边。
- 优化首页、登录页及整体页面样式。
- 优化认证与请求处理逻辑。
- 优化构建、包管理与发布流程，切换至 pnpm workspace，调整 electron-builder 与发布配置。
- 优化项目结构，合并重复工具模块，提升代码复用率。
