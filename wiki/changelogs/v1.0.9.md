# v1.0.9

## Added
- Docker support: `Dockerfile`, `docker-compose.yml`, LevelDB adapter, and containerized server, plus a GitHub Actions workflow to build and publish Docker images.
- New account management page and corresponding user/file API modules in the web app.
- Expanded localization strings (English and Chinese) for the new UI.

## Improved
- Major UI refresh and optimization across the app, especially the detail page and file page.
- Refined copy, styling, and layout in settings, start page, and shared components.
- Enhanced server, file database, settings, and account utilities.
- Improved release automation and utools preload dependency scripts.

## Docs
- Updated development and feature documentation.
